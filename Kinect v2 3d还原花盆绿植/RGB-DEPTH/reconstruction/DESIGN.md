# 25帧旋转点云配准 — 旋转轴估计 & 全局拼接

## 核心问题

手动转台 → 旋转轴方向/位置未知 → 不能用理论 14.4°/Y轴做初始变换 → 现有代码失败。

## 目标

从25帧数据中反推旋转轴参数，实现360°闭环拼接。

## 技术路线

### Phase 1: 数据加载 & 花盆分割
- 深度图 → 点云 (Kinect V2 内参)
- 彩色映射
- 分割花盆刚性区域: ExG植物掩膜取反 + Y轴高度阈值

### Phase 2: 旋转轴估计 (核心)
**方法: 花盆刚性区域配准 → 手眼标定反推旋转轴**

```
For i = 1:24:
    pot_cloud_i, pot_cloud_i+1 → FGR全局配准(无初值)
    提取变换矩阵 T_i (R_i, t_i)

对所有成功的 T_i:
    旋转轴方向 a = 各R_i旋转轴方向的鲁棒平均
    旋转中心 c = 解超定方程组: t_i = (I - R_i) * c  (对所有i)
    旋转角度 = 从R_i提取, 取中位数验证是否为14.4°
    轴位置验证: c应在花盆质心附近
```

**为什么这样做:**
- FGR全局配准**不依赖初值**，14.4°转角在其处理能力内
- 花盆是唯一刚性区域，排除叶片干扰
- 25帧联合求解比单对配准统计上稳健得多
- 25帧提供了24个相邻变换，足够压制噪声

### Phase 3: 轴约束配准
- 用估计轴 + 理论转角初始化所有25帧的ICP
- 逐帧精配准 (Colored ICP)
- 闭环约束: 第25帧应回到第0°位置

### Phase 4: Pose Graph全局优化
- 节点: 第1,2,...,25帧的位姿
- 边: 相邻帧约束 + 闭环约束
- 优化后融合输出PLY

### 回退策略
- FGR失败 → RGB SIFT特征匹配 → 3D提升 → RANSAC
- 轴估计不可靠(<15帧通过) → 直接Pose Graph用FGR结果
- 全部失败 → 建议用标定物重拍
